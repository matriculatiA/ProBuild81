# ProBuild81

Demo уебсайт за фирма за довършителни ремонти, ремонт на бани и покривни услуги.
Дизайнът комбинира елементи от [certainteed.com](https://www.certainteed.com/) (корпоративно доверие, статистика, "why us" секция) и [angi.com](https://www.angi.com/) (hero форма за оферта, категории услуги с икони, карти с проекти и рейтинги, "cost guides" секция).

Статичен сайт (HTML/CSS/JS, без build стъпка), хостнат чрез GitHub Pages.

## Локално разглеждане

Отворете `index.html` директно в браузър, или стартирайте локален сървър:

```
npx serve .
```

## Структура

- `index.html` — цялото съдържание на страницата
- `assets/css/style.css` — стилове
- `assets/js/main.js` — мобилно меню, форма за оферта (demo, без бекенд)
